# Simscraft
A housing quality-of-life addon.

## AutoBuy
Simscraft features a (state-of-the-art) shopping cart, usable at any vendor that sells decor. Simply shift-click on the item you want to add to the cart, and voila. You can change the amount you want to buy in the editbox, or by shift-clicking the item repeatedly.

Once you're happy with your cart, click purchase. For the server's sake, the rate at which you can buy items is quite low, so it might take a while. But it's better than doing it manually!

## Custom Music
Simscraft comes with the ability to play music while you're in the house editor.

To add your own music:
- Copy the music file (mp3 files only) to the Assets/ folder inside the addon.
- Add an entry to the table in the `MusicDefinitions.lua` file using the file name as the key, and the duration (in seconds) as the value. Do not include the file extension in the file name.

To play your music, first enable the feature in the Blizzard settings panel, then enter the editor!

## Grid-snap Toggle
If you're used to playing The Sims, this one will fit right in. When enabled, allows the user to temporarily disable grid snapping for decor while the Alt key is held.
